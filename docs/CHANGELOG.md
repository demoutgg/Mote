# 版本记录

## v0.10.1

**macOS**

- 设置窗口顶部改为「居中标题 + 居中图标分页」两行版式，取代系统工具栏，红绿灯回到标准位置
- 新增「关于」分页：应用图标、版本与构建号、GitHub 链接、隐私说明；「关于」不再放在通用页，状态栏菜单也去掉了「关于 Mote」
- 通用页重排：缺权限时的提醒条放在最上，菜单栏图标设置移到弹窗设置之后
- 权限不再常驻两行表格，改为缺权限时出现的提醒条，全部授权后自动收起
- 弹窗顶栏高度 44 → 36，去掉顶栏下方的空白
- 翻译结果分隔线改用共享图案、流式输出按 60ms 合批，双服务峰值内存 46 → 37 MB
- 快捷键录制框改为输入框样式，去掉灰色填充
- 更新文档截图与资源占用实测数据

## v0.10.0

**macOS**

- 新增 `Theme.swift` 统一字号、圆角、间距与语义色，设置页、翻译弹窗、权限引导、历史页、快捷键录制器全部改用它，不再各处硬编码
- 设置窗口导航由顶部分段控件改为工具栏图标分页，呈现系统偏好设置的样式
- 卡片去掉 1pt 描边，改用底色分层；行高 44 → 38，行与行之间加分隔线
- 输入框改为圆角样式并统一高度；服务页的接口地址、API Key、模型等输入框靠右对齐成一列，`自定义` 预设与 `获取模型` 按钮移到输入框左侧
- 连接测试的结果显示在「连接测试」行内，不再撑高卡片、顶动下方内容
- 翻译弹窗：多个服务的结果按服务分段，每段有服务名与分隔线；单服务时不显示标题，也不再重复引擎标签
- 翻译按钮改为自绘的强调色圆角按钮，禁用与按下状态单独处理
- 修复窗口开着切换深浅色时卡片、弹窗底色不刷新，深色下卡片变成白底的问题
- 修复历史页行内容比标题栏缩进多一圈、译文单行截断且没有省略号的问题
- 更新文档截图

## v0.9.0

**macOS**

- 授权流程重做：缺权限时弹出一个引导窗，两项权限各占一行，点「授权」后主窗让位，屏幕上跟随系统设置窗口出现一张可拖动的应用卡片，授权完成自动收起
- 权限状态改由 `MoteOCR` 子进程查询。此前主进程读到的是缓存值，会出现「系统里已勾选、Mote 里仍显示未授权」以及「未授权却不弹提示」
- 设置窗口重做：通用 / 服务 / 翻译 / 历史四页，固定窗口高度，页面内滚动，底部常驻保存
- 设置 → 通用新增权限状态与授权入口
- 状态栏菜单精简：去掉使用指南与两个权限项，快捷键不再显示无效的按键提示
- 删除首次引导窗口，权限说明并入设置页
- 快捷键录制会拒绝 `⌘Q`、`⌘W`、`⌘Tab` 等系统保留组合并给出提示
- 历史记录：两行布局（原文 + 译文 + 时间）、支持搜索、复制原文/译文、空态提示，清空确认统一
- 翻译弹窗：原文自动换行、重新打开时回到开头、多结果并排、翻译按钮改为主按钮样式
- 内存：空闲约 11 MB，长时间反复使用后稳定在 38 MB 左右

**修复**

- 设置窗口里点「测试连接」「获取模型」后立即关窗会崩溃
- 翻译弹窗不可见时仍吞掉 Esc，导致设置窗口无法用 Esc 取消
- 两个服务都关闭时仍可保存设置
- API Key 首尾的空格与换行没有清理，导致请求 401

**Windows**

- 补齐与 macOS 对齐的功能：可自定义快捷键、系统提示词、自动复制、弹窗尺寸与位置记忆、失焦收起、历史搜索与复制原文/译文、AI 预设与获取模型、关于菜单
- 设置窗口改为四页布局
- **未经实机自测**，仓库不提供预编译产物，需自行编译
