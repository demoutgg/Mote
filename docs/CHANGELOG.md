# 版本记录

## v0.9.0

**macOS**

- 授权流程重做：缺权限时弹出一个引导窗，两项权限各占一行，点「授权」后主窗让位，屏幕上跟随系统设置窗口出现一张可拖动的应用卡片，授权完成自动收起
- 权限状态改由 `MoteOCR` 子进程查询。此前主进程读到的是缓存值，会出现「系统里已勾选、Mote 里仍显示未授权」以及「未授权却不弹提示」
- 设置窗口重做：通用 / 服务 / 翻译 / 历史四页，固定窗口高度，页面内滚动，底部常驻保存
- 设置 → 通用新增权限状态与授权入口
- 状态栏菜单精简：去掉使用指南与两个权限项，快捷键不再显示无效的按键提示
- 删除首次引导窗口，权限说明并入设置页
- 快捷键录制会拒绝 `⌘Q`、`⌘W`、`⌘Tab` 等系统保留组合并给出提示
- 历史记录：两行布局（原文 + 译文 + 时间）、支持搜索、复制原文/译文、空态提示，清空确认统一
- 翻译弹窗：原文自动换行、重新打开时回到开头、多结果并排、翻译按钮改为主按钮样式
- 内存：空闲约 11 MB，长时间反复使用后稳定在 38 MB 左右

**修复**

- 设置窗口里点「测试连接」「获取模型」后立即关窗会崩溃
- 翻译弹窗不可见时仍吞掉 Esc，导致设置窗口无法用 Esc 取消
- 两个服务都关闭时仍可保存设置
- API Key 首尾的空格与换行没有清理，导致请求 401

**Windows**

- 补齐与 macOS 对齐的功能：可自定义快捷键、系统提示词、自动复制、弹窗尺寸与位置记忆、失焦收起、历史搜索与复制原文/译文、AI 预设与获取模型、关于菜单
- 设置窗口改为四页布局
- **未经实机自测**，仓库不提供预编译产物，需自行编译
